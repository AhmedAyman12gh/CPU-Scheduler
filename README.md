# CPU Scheduler Simulator

## 📌 Project Description

This project is a **CPU Scheduling Simulator** that demonstrates how different scheduling algorithms work in operating systems.
The simulator allows users to visualize process execution and compare performance between algorithms.

---

## ⚙️ Features

* Implementation of multiple scheduling algorithms:

  * First Come First Serve (FCFS)
  * Shortest Job First (SJF) – Preemptive & Non-Preemptive
  * Priority Scheduling – Preemptive & Non-Preemptive
  * Round Robin (RR)

* Live simulation (1 second = 1 time unit)

* Dynamic process addition during execution

* Gantt Chart visualization (live)

* Remaining Burst Time table (updated in real-time)

* Calculation of:

  * Average Waiting Time
  * Average Turnaround Time
